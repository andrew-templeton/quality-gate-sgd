# Work roadmap

The current directed dependency graph is [docs/work/README.md](work/README.md), generated from [graph.json](work/graph.json). It includes repository extraction, API hardening, cross-repository conformance and the prerequisites for a stable release.

Update the JSON source, run `npm run plan:generate`, and validate it with `npm run plan:check`. Completed work needs evidence and completed prerequisites.

The original software-engine roadmap is preserved in [quality-sgd-software](https://github.com/andrew-templeton/quality-sgd-software/blob/main/docs/ROADMAP.md). Historical research plans do not imply that their experiments or qualifications have been completed.
