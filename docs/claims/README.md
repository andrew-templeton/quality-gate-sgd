# Claim Graph Format

This folder defines a deterministic, machine-readable representation of paper claims
and their supporting evidence. It is intended to let you run quality-gate style
analysis on the paper itself.

## Files
- `claim-graph.schema.json` - JSON Schema for the claim graph

## Core Concepts
- **Claim node**: a single statement that requires proof, citation, or validation
- **Evidence**: a proof, citation, or experiment that supports a claim
- **Edge**: dependency or support relationship between claims

## Suggested Workflow
1) Extract or curate claims into a `claim-graph.json` file
2) Run the analysis script to compute coverage and priority
3) Iterate: add proofs/citations/experiments to reduce gaps

## Status Semantics
- `proven`: fully proven in-text (proof exists in the paper)
- `cited`: supported by a specific reference
- `novel`: new claim requiring validation or experiment
- `pending`: claim without sufficient evidence yet
- `hypothesis`: explicitly speculative

## Support Scores
Support scores are continuous in [0, 1], to allow gradient-like descent:
- `supportScore`: how directly the evidence supports the claim
- `coverageScore`: how much of the claim is covered by the evidence

These can be generated by an LLM or curated manually.

## CLI (scripts/claim-graph.ts)
Examples:

```bash
# Extract from existing claims table
npx tsx scripts/claim-graph.ts extract -claims-md docs/theory/CLAIMS.md -out docs/claims/claim-graph.json

# Extract from prose using an LLM (OpenAI or Anthropic)
npx tsx scripts/claim-graph.ts extract -input docs/CONCEPT.md -provider openai -model gpt-5.2 -out docs/claims/claim-graph.json

# Merge claims table + prose into one graph
npx tsx scripts/claim-graph.ts extract -claims-md docs/theory/CLAIMS.md -input docs/CONCEPT.md -provider openai -model gpt-5.2 -out docs/claims/claim-graph.json

# Analyze and score gaps
npx tsx scripts/claim-graph.ts analyze -graph docs/claims/claim-graph.json -out docs/claims/claim-graph.analysis.json

# Score citation support (requires citations metadata)
npx tsx scripts/claim-graph.ts score-citations -graph docs/claims/claim-graph.json -citations docs/claims/citations.json -provider anthropic -model opus-4.5 -out docs/claims/claim-graph.scored.json
```

## JSON Guarantees
OpenAI calls use the Responses API with JSON Schema structured outputs when possible.
The tool then validates the returned JSON against a strict schema and fails fast if it does not match.
